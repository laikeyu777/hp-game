# 《一指登塔：灰烬回廊》像素战斗美术设计

## 目标

将当前 Canvas 中的圆形角色和敌人替换为可辨认的像素人物，并增加服务于战斗判断的动态效果。设计基于用户确认的 V4 细节稿与 V5 动态稿，保持完全离线、手机竖屏和低性能设备可运行。

本次只调整战斗画面的绘制与表现，不改变伤害、攻击频率、敌人数量、奖励、存档或楼层流程。

## 视觉规格

### 冒险者

- 使用 32 x 48 像素逻辑骨架，通过 Canvas 整数倍放大绘制。
- 核心识别元素：灰白短发、单侧面罩、橙色余烬眼、黄铜护肩、墨绿胸甲、皮革腰带、护腕、深色靴子和破损暗红披风。
- 人物细节包括发丝明暗、面罩扣件、护甲铆钉、皮革缝线、刃口高光和披风破口。
- 保持左侧披风与右侧武器构成的非对称轮廓，确保缩小后仍易识别。

### 武器

- 长剑：暖白刃口、青色冷光边、黄铜护手。普攻使用橙色扇形火弧和方形火星。
- 法杖：木质杖身、紫色晶核、青色符文环。普攻使用青色符文弹与紫色范围波纹。
- 弩：黄铜弩臂、深木机匣、青色弦光。普攻使用短促箭矢和高速残线。

### 敌人

- 灰烬侍从：焦黑皮肤、破损头盔、短刀、发光余火胸腔；刀刃变红表示即将斩击。
- 回廊猎犬：裂隙鬃毛、发光眼、獠牙、低伏四足轮廓；紫色前影表示即将扑击。
- 裂甲守卫：重甲、塔盾、断枪和明显甲片裂纹；枪尖变亮表示即将突刺。
- 塔顶守门人：冠角头盔、浮动肩甲、裂隙核心和长柄权杖；第二阶段核心张开并转为橙色脉冲。

## 动画规格

动画采用 12 FPS 的离散像素节奏，位置和尺寸取整，关闭 Canvas 图像平滑。

- 待机：两到四帧呼吸起伏、低频披风摆动和余烬眼闪烁。
- 普攻：起手前倾、武器主体移动、残影、命中停顿、目标闪白和方形碎屑。
- 裂火冲击：地面符文展开、手部蓄光、火矛飞行、命中核心、外圈冲击波五个阶段。
- 状态：燃烧使用橙色像素火焰，减速使用青色符文环，优先目标继续使用黄色轮廓。
- 敌人攻击：先播放约 350 到 500 毫秒预警，再播放攻击动作；预警颜色必须与现有红色危险语义一致。
- 首领阶段：核心脉冲、肩甲浮动和二阶段橙色能量外溢，不使用持续全屏闪烁。

## 技术设计

### 模块边界

新增 `pixel-art.js`，只负责绘制像素角色、敌人、武器和特效，不读取 DOM，不结算伤害，也不修改存档。

`game.js` 继续拥有战斗状态，并向像素绘制模块传入只读渲染数据：

- 当前时间与动画起始时间
- 武器类型
- 角色位置、生命和受击状态
- 敌人类型、位置、生命、燃烧、减速、攻击预警和首领阶段
- 当前活动特效列表

动态特效使用短生命周期对象：`type`、`startTime`、`duration`、`from`、`to` 和可选颜色。渲染循环删除已结束特效，战斗规则仍由 `combat-logic.js` 处理。

### 渲染流程

每次绘制依次完成：塔楼背景、地面区域、角色和敌人阴影、人物与武器、状态标记、普攻或技能特效、攻击预警、生命条和目标轮廓。

现有 90 毫秒战斗逻辑定时器保持不变。视觉动画使用 `requestAnimationFrame`，只读取战斗快照，不推动伤害结算。暂停时停止动画时间推进，恢复后从原进度继续。

### 性能边界

- 不加载外部图片、字体或网络资源。
- 不使用粒子库、WebGL、滤镜模糊或大面积逐像素运算。
- 同时存在的短生命周期特效最多 32 个；超过上限时优先丢弃最旧的装饰碎屑。
- `prefers-reduced-motion` 下关闭披风摆动、呼吸和装饰碎屑，保留攻击预警与命中反馈。
- Canvas 继续使用现有 360 x 390 内部分辨率，按容器缩放，避免提高实际像素数量。

## 状态与容错

- 未知武器回退为长剑外观。
- 未知敌人回退为灰烬侍从外观。
- 缺少动画时间时绘制待机第一帧。
- 页面切到后台时不累计视觉动画帧；回到前台后按当前战斗状态重新绘制。
- 特效绘制异常不得阻止战斗结算；渲染模块输入使用默认值并限制数值范围。

## 测试与验收

- 为动画帧选择、时间归一化、特效生命周期和数量上限增加无 DOM 单元测试。
- 验证长剑、法杖和弩分别显示独立人物武器与普攻效果。
- 验证三种普通敌人和首领均使用独立外貌。
- 验证裂火冲击完整播放蓄力、飞行和命中阶段，但伤害只结算一次。
- 验证暂停期间视觉动画不推进，恢复后从原动画进度继续。
- 验证燃烧、减速、受击闪白和攻击预警不会相互遮挡。
- 在 390 x 844 视口检查无横向溢出、底部操作区无遮挡、人物和敌人轮廓清晰。
- 连续运行完整一层战斗，浏览器控制台无错误，动画画面持续变化且 Canvas 非空。

## 不在本次范围

- 新角色、新敌人或新技能。
- 战斗数值和平衡调整。
- 骨骼动画、外部精灵图编辑器或 WebGL 渲染。
- 菜单立绘、剧情过场和音效系统。

## 敌人攻击特效补充

敌人攻击保留现有战斗计时和伤害数值，但在真实伤害事件发生时增加一次视觉跟随动作。预警仍负责表达即将攻击，跟随动作负责表达出手与命中，二者都不能调度或结算伤害。

- 灰烬侍从：红色像素斩击弧，持续 260ms。
- 回廊猎犬：紫色跃扑残影与落地冲击，持续 320ms；减少动态模式下省略残影，仅保留落地反馈。
- 裂甲守卫：黄色长枪突刺，持续 280ms。
- 塔顶守门人：橙紫方形领域脉冲，持续 420ms。
