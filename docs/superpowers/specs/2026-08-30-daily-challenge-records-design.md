# 每日挑战与个人最佳记录设计

## 目标

为《一指登塔：灰烬回廊》增加完全离线的每日挑战和个人最佳记录。相同挑战码必须生成相同的房间、强化、事件和概率结果，让玩家可以分享挑战码与成绩文本进行比较，同时不引入账号、服务器或网络依赖。

## 功能范围

首版包含：

- 按北京时间每日生成固定挑战码
- 输入并重玩受支持版本的历史挑战码
- 固定路线房间、强化卡、事件、暴击、点燃与 Boss 随机机制
- 每日挑战综合评分和结算明细
- 历史最高分、最快通关、最高层数与三种武器最高分
- 今日最好成绩和最近 30 次挑战记录
- 复制挑战码与复制成绩文本
- 旧存档向新版结构的兼容迁移

首版不包含在线排行榜、账号、云存档、好友列表或防修改系统。

## 公平规则

每日挑战不应用永久成长中的初始生命、初始金币、战斗韧性和稀有率加成。普通冒险继续应用这些加成。

玩家可以使用自己已经解锁的武器和主动技能。成绩记录武器与技能，便于按流派比较。强化套装、局内主动技能升级、路线选择和操作时机继续由玩家决定。

挑战计时只统计实际游玩时间。暂停期间不计时；主动退出按失败结算；刷新或关闭页面视为中断，不提交正式成绩。

## 挑战码

挑战码格式：

```text
ASH-YYYYMMDD-V<规则版本>-<四位校验码>
```

示例：

```text
ASH-20260830-V1-7K3P
```

字段含义：

- `ASH`：游戏标识
- `YYYYMMDD`：北京时间日期
- `V1`：挑战生成和计分规则版本
- 四位校验码：由日期、版本和固定命名空间计算，用于发现输入错误

系统按 `Asia/Shanghai` 的自然日生成今日挑战。解析挑战码时需要校验格式、有效日期、规则版本和校验码。未知版本显示“当前版本暂不支持”，其他错误显示“挑战码格式无效”。

## 固定随机系统

新增独立模块 `challenge-system.js`。模块以挑战码派生 32 位种子，并创建可重复的伪随机数生成器。每日挑战开始时创建本局随机源，普通冒险继续使用系统随机数。

挑战随机源覆盖：

- 路线房间类型
- 强化卡洗牌与抽取
- 随机事件选择
- 普攻暴击
- 点燃等概率命中效果
- 楼层结束后的事件触发
- Boss 机制中当前依赖时间或随机数的选择

玩家输入、攻击时间、技能释放时间和路线选择不固定。为避免不同操作消耗随机数后让无关系统发生漂移，每类随机行为使用从主种子派生的独立随机流，例如 `combat`、`rewards`、`rooms`、`events` 和 `boss`。派生键还需包含楼层及必要的序号。

这种分流保证玩家改变某一层的战斗操作时，不会意外改变之后所有强化或房间结果。

## 综合评分

结算基础公式：

```text
总分 =
  已通过层数 * 1000
  + 击败普通敌人数 * 40
  + 击败 Boss 数 * 600
  + floor(剩余生命比例 * 500)
  + 持有金币 * 5
  + 通关奖励
  + 速通奖励
```

通关奖励：完成第 50 层时增加 `10000` 分，否则为 `0`。

速通奖励只在完成第 50 层时生效：

```text
max(0, 6000 - floor(通关秒数) * 10)
```

所有分项最终取非负整数。失败时“已通过层数”只包含已经完成的楼层，不包含当前失败楼层。

成绩比较顺序：

1. 综合分更高
2. 已通过层数更多
3. 实际游玩时间更短
4. 剩余生命比例更高

完全相同则保留较早提交的成绩为该挑战码最佳记录。

## 运行统计

每日挑战的运行状态新增：

- 模式：`normal` 或 `daily`
- 挑战码、挑战日期和规则版本
- 开始时间、累计暂停时间和实际游玩时间
- 已击败普通敌人数
- 已击败 Boss 数
- 已完成楼层数
- 结算时剩余生命、最大生命和金币
- 是否完成第 50 层

计时使用单调时钟计算本次页面生命周期内的耗时，避免系统时间在对局中改变造成负数或跳变。结算记录使用系统时间仅作为展示用提交时间。

## 个人最佳记录

记录以下项目：

- 历史最高综合分
- 最快完成 50 层的实际游玩时间
- 历史最高已完成层数
- 长剑最高分
- 法杖最高分
- 弩最高分
- 每个挑战码的个人最好成绩
- 最近 30 次完成结算的每日挑战

最高层数和各武器最高分由有正式结算的普通冒险与每日挑战共同更新。综合分只有每日挑战具备，因此历史最高综合分来自每日挑战。最快通关可由普通冒险和每日挑战共同更新，但必须完成第 50 层。

同一挑战码允许重复挑战。`dailyBest` 只保留该码最优成绩，`recentRecords` 保留每次正式结算，超过 30 条后删除最旧记录。中断局不写入记录。

## 存档结构与迁移

存档版本升级为 `version: 5`，新增：

```js
challenge: {
  personalBest: {
    highestScore: 0,
    fastestClearMs: null,
    highestFloor: 0,
    weapons: {
      sword: 0,
      staff: 0,
      crossbow: 0
    }
  },
  dailyBest: {},
  recentRecords: []
}
```

每日挑战记录包含：

```js
{
  code: "ASH-20260830-V1-7K3P",
  date: "2026-08-30",
  rulesVersion: 1,
  weapon: "staff",
  skill: "staff-meteor",
  score: 52840,
  completedFloors: 46,
  durationMs: 391000,
  hpRatio: 0,
  enemiesDefeated: 112,
  bossesDefeated: 4,
  cleared: false,
  submittedAt: "2026-08-30T12:00:00.000Z"
}
```

加载旧存档时深度补齐新增字段，不修改现有余烬、武器、技能、永久升级、深渊、成就与图鉴数据。导入存档时过滤字段类型错误、未知武器、负数成绩和无法解析的挑战码；单条坏记录不会导致整个存档无法导入。

## 界面设计

主菜单新增两个拇指友好的入口：

- `每日挑战`
- `个人记录`

每日挑战页面显示今日挑战码、复制按钮、挑战码输入框、校验结果、所选武器与主动技能、该挑战码个人最好成绩和开始挑战按钮。输入框支持忽略大小写和首尾空格，成功解析后统一显示标准大写格式。

个人记录页面显示四项核心记录、三种武器最高分、今日最好成绩和最近挑战列表。无记录时使用明确的空状态，不显示无意义的零时间。

结算页在每日挑战模式下增加综合分、分项、用时、层数、挑战码和新纪录提示，并提供“复制成绩”按钮。普通冒险结算只显示其刷新到的最高层、最快通关或武器记录，不显示挑战综合分。

分享文本格式：

```text
《一指登塔：灰烬回廊》
挑战码：ASH-20260830-V1-7K3P
武器：法杖
成绩：52,840
层数：46
用时：06:31
```

优先使用 Clipboard API；不可用或权限失败时回退到临时文本选择复制，并显示成功或失败提示。

## 模块边界

`challenge-system.js` 提供纯函数接口：

- `createDailyChallenge(date, rulesVersion)`
- `parseChallengeCode(code)`
- `createSeededRandom(seed)`
- `createRandomStream(challenge, category, floor, index)`
- `calculateScore(summary)`
- `compareResults(left, right)`
- `updatePersonalBest(challengeSave, result, mode)`
- `sanitizeChallengeSave(value)`
- `formatDuration(durationMs)`
- `formatShareText(result)`

`game.js` 负责模式选择、运行状态、将正确的随机流传给现有系统、收集统计和提交结算。`room-logic.js` 与 `combat-logic.js` 继续通过已有的 `random` 参数接收随机源。

`index.html` 和 `styles.css` 只负责新增页面、记录列表与结算展示，保持 390 x 844 竖屏无横向溢出、主要点击区域不小于 44 x 44 px。

## 自动保存

挑战开始时不写入可恢复的对局快照。每层原有自动保存仍可保存账户层面的解锁与图鉴，但不能让刷新后续接每日挑战。只有胜利、失败或主动退出产生正式成绩。

挑战结算更新个人最佳、每日最佳和最近记录后立即持久化到 localStorage 与 IndexedDB。导出 JSON 自动包含记录；重置存档同时清除记录。

## 测试与验收

纯函数测试覆盖：

- 同日期和版本生成相同挑战码
- 不同日期生成不同挑战码
- 有效码解析、大小写规范化及无效码拒绝
- 相同随机流产生相同序列
- 不同类别或楼层的随机流互不干扰
- 评分公式、失败层数、速通奖励和并列排序
- 个人最佳、武器最佳、最快通关和最近 30 条裁剪
- v4 存档迁移与异常记录过滤

集成测试覆盖：

- 每日挑战禁用永久数值加成
- 相同挑战码重复运行时房间、事件、强化和概率序列一致
- 普通冒险仍使用永久成长与非固定随机
- 结算正确更新记录并自动保存
- 中断局不生成成绩
- 导入导出保留挑战记录

浏览器验证覆盖 390 x 844 和桌面视口，检查无横向溢出、按钮可触摸、页面切换正确、复制反馈明确、控制台无错误，并验证 Service Worker 缓存新增脚本和版本资源。
