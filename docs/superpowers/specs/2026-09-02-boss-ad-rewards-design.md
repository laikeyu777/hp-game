# Boss 登场与广告奖励设计

## 目标

为《一指登塔：灰烬回廊》增加明确的 Boss 登场仪式，以及两个互不混淆的激励广告入口：战斗失败后的单局复活和大厅中的余烬领取。游戏在离线、本地预览或虎扑广告能力不可用时仍可正常游玩和结算。

## 已确认规则

- Boss 层为第 10、20、30、40、50 层，进入战斗时显示登场遮罩、大字幕、Boss 名称和专属机制。
- Boss 登场动画约 1.6 秒；动画期间暂停战斗计时和伤害结算。
- 登场反馈包含暗红闪光、轻微屏幕震动和专属低沉音效；系统开启减少动态效果时关闭震屏并缩短动画。
- 战斗死亡后可观看广告复活当前战斗一次；每局最多使用一次，不设每日次数上限。
- 复活恢复最大生命值的 35%，清除当前敌人攻击预警并继续战斗；复活广告不赠送余烬。
- 大厅余烬数字旁提供 `+` 入口；成功观看广告后获得 80 余烬，每天最多领取 3 次。
- 余烬广告的领取次数按北京时间日期重置；复活广告次数与余烬广告次数分开统计。
- 每日挑战默认不显示广告复活和余烬广告，避免影响竞技成绩的公平性。
- 广告加载失败、用户关闭、离线、宿主接口不存在或每日次数用尽时，不发奖励、不扣余烬广告次数，并保留正常失败结算。

## 架构

### Boss 登场层

`game.js` 在 `beginBattle()` 识别 Boss 后创建 `state.bossIntro`，内容包括 `startedAt`、`durationMs`、`name` 和 `mechanic`。`tick()` 在登场窗口内直接返回，`renderCombatFrame()` 继续绘制背景但显示遮罩。动画结束后清理状态并恢复计时。UI 在 `index.html` 增加独立的 `boss-intro-overlay`，避免复用普通 `arena-toast` 导致样式和生命周期互相干扰。

`playFeedback('boss-arrival')` 使用现有 WebAudio 设置生成低频三段式提示音；震动使用短序列，并由 `save.settings.vibration` 控制。`prefers-reduced-motion` 时不执行震屏，仅保留短暂可读字幕。

### 广告服务层

在 `hupu-platform.js` 增加 `showRewardedAd({ placement })`。该方法只探测虎扑宿主提供的官方广告桥接对象并返回结构化结果：

```js
{ ok: true, placement: 'revive' }
{ ok: false, reason: 'offline' | 'host_unavailable' | 'load_failed' | 'dismissed' | 'timeout' }
```

广告桥接未提供时不得把本地模拟当成成功。适配层保留超时和异常捕获，使广告失败不会阻塞游戏。

### 存档状态

`defaultSave` 和 `loadSave()` 增加版本兼容字段：

```js
ads: {
  essenceDate: 'YYYY-MM-DD',
  essenceClaims: 0
}
```

跨日读取时将 `essenceClaims` 重置为 0。运行时 `state.reviveUsed` 在每局开始时设为 `false`，不写入存档。余烬领取成功后先更新存档再刷新大厅显示；复活成功只更新运行时状态。

## 交互流程

### Boss

1. 玩家从路线选择进入 Boss 层。
2. 显示全屏遮罩，依次显示 `BOSS 降临`、Boss 名称和机制提示。
3. 遮罩结束，战斗开始；已有 Boss 机制预警继续按原逻辑运行。

### 失败复活

1. 普通模式死亡后，结果页显示“观看广告复活”按钮和“本局可用 1 次”。
2. 点击后进入加载状态，按钮不可重复点击。
3. 广告成功：恢复战斗、恢复 35% 最大生命、清除预警、标记 `reviveUsed`。
4. 广告失败或用户关闭：显示原因，保持失败结算按钮可用。
5. 已复活过或每日挑战模式：不显示该入口。

### 余烬领取

1. 大厅显示余烬数值和 `+` 按钮。
2. 点击后显示当日剩余次数。
3. 成功观看广告后增加 80 余烬，次数加 1 并自动保存。
4. 达到 3 次、离线或广告失败时显示原因，不改变余烬。

## 测试范围

- Boss 登场只在 Boss 层创建，普通层不创建。
- 登场窗口内战斗 tick 不造成伤害，结束后恢复。
- 减少动态效果设置关闭震屏。
- 新局 `reviveUsed` 为 false；复活成功后变为 true，同一局不能再次复活。
- 余烬广告首次、第三次成功分别获得 80 和累计 240 余烬，第四次被拒绝。
- 余烬广告跨北京时间日期后次数重置。
- 广告离线、宿主缺失、加载失败、关闭和超时均不扣次数、不发奖励。
- 每日挑战隐藏两个广告入口。
- 保留原有战斗、存档、排行榜和全量测试通过。

## 非目标

- 不在普通浏览器中伪造广告播放或成功回调。
- 不修改排行榜计分公式，不让广告影响每日挑战成绩。
- 不新增服务端广告记录；广告次数和余烬奖励先由本地存档管理，真实商业化数据由虎扑官方广告平台负责。
