# 一指登塔：灰烬回廊

适合手机竖屏、单手操作的离线肉鸽爬塔原型。游戏本地运行即可开始挑战、完成结算并保存进度；网络不可用不会阻断战斗。

## 本地运行

在项目目录启动任意静态文件服务器，然后在浏览器访问其地址。例如已安装 Node.js 时：

```powershell
npx serve .
```

使用手机调试时，让手机和电脑处于同一局域网，并访问电脑显示的局域网地址。生产环境请使用 HTTPS，以便 Service Worker 缓存离线资源。

## 虎扑排行榜

排行榜客户端会优先使用虎扑宿主注入的以下能力：

- `ColorboxAI.auth.getUserInfo()`：读取登录态与虎扑昵称。
- `ColorboxAI.cloud.request()`：提交成绩、读取每日榜和历史总榜。

在普通浏览器、未登录虎扑或离线时，游戏仍可完整游玩。结算成绩会保留在本地待同步队列；再次进入虎扑宿主且网络可用时会尝试同步。页面只显示虎扑昵称，不提供自定义昵称，也不会上传完整存档、手机号或设备信息。

## 部署前置条件

客户端适配和 API 契约已经具备，但云端排行榜尚未自动部署。上线前需要：

1. 在虎扑活动环境部署 `/api/leaderboard/list`、`/api/leaderboard/me`、`/api/leaderboard/submit`，详情见 `docs/superpowers/specs/2026-09-02-hupu-leaderboard-api-contract.md`。
2. 服务端从虎扑宿主认证上下文取得账号身份，不能接受客户端传来的账号 ID。
3. 服务端重新计算积分，并校验层数、武器、每日挑战码、用时和重复提交键。
4. 配置活动 API 基地址，并在虎扑登录、离线、超时和重复提交场景完成冒烟测试。

未完成这些步骤前，排行榜将以本地缓存和待同步状态运行，不应宣称云端榜单已经上线。
